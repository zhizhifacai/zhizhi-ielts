经验方法论

🎧 听力精听三步法

  • 听不懂反复盲听，直到能抓住关键词
  • 写不出看原文跟读，强化语音拼写连接
  • 写错整理易混词、拼写错误本
  • 王陆语料库考前刷 2遍
  • 每日英美剧/电影 20分钟，保持语感

📖 阅读复盘四步法

  • ① 错误原因归类
  • ② 锁定错误段落意思
  • ③ 找出题干对应的正确段落意思
  • ④ 对照题干短语和原文短语的同义替换
  • 每日积累 刘洪波538 同义替换词

✍ 写作双师框架

  • 框架：Simon考官 + 杜仕明写作课
  • 小作文：折线图 / 柱状图 / 饼图 / 表格 / 地图 / 流程图
  • 大作文：是否同意 / 利弊分析 / 双边讨论 / 报告类
  • 每次训练后用 多次元雅思AI 批改
  • 重点训练段落与段落之间的逻辑链

🗣 口语三件套

  • 跟练 薛麦 每日约 2h（可拆分早/晚）
  • Part 2 用素材串题，减少记忆负担
  • 随机抽题模拟考场，训练即时反应
  • 录音回听，纠正发音与语法错误
